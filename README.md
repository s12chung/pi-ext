# pi-ext

Extensions for [pi](https://github.com/earendil-works/pi).

| Extension                            | Description                                                                                                                                                        |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`plan-mode`](plan-mode)             | Read-only exploration mode. See [plan-mode/README.md](plan-mode/README.md).                                                                                        |
| [`starship-footer`](starship-footer) | Replaces the footer with [pi-zentui](https://github.com/lmilojevicc/pi-zentui)'s starship status line. See [starship-footer/README.md](starship-footer/README.md). |
